# Financial Analysis Wiki · GitHub Pages 發布包

此資料夾可直接作為 GitHub Pages Repository 根目錄。

- `index.html`：Wiki 知識展示首頁，含五個主題及搜尋篩選。
- `slides.html`：八頁 HTML 教學簡報（已修正的版本）。
- `workflow_report.md`：Loop / Graph 與反思。
- `submission_summary.md`：繳交摘要，網址欄位在發布後填寫。

提醒：本展示包不包含你本機完整的 Python/SQLite 執行環境及歷史 logs。請保留原專案 `database/`、`scripts/`、`logs/` 供老師檢查；需要公開程式碼可先確認資料授權與是否含個人資訊，避免直接上傳抓取的完整文章內容。

## 發布
1. 在 GitHub 建立公開 repository，例如 `financial-analysis-wiki`。
2. 將本資料夾四個成果檔與 README 上傳到 repository 根目錄。
3. Settings → Pages → Build and deployment → Deploy from a branch → main → /(root) → Save。
4. Pages 生效後，首頁為 `https://<username>.github.io/financial-analysis-wiki/`，簡報為 `https://<username>.github.io/financial-analysis-wiki/slides.html`（以 GitHub 實際顯示為準）。
5. 用 Safari 開啟公開網址，再次測試引用、測驗及切頁。
